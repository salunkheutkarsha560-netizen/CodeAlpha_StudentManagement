# Student Management System in C

A menu-driven Student Management System developed in C as part of the CodeAlpha C Programming Internship — Task 3.

## Features

- **Add Student:** Add a student record with roll number, name, and marks.
- **Display Students:** View saved student records.
- **Search Student:** Find a student using their roll number.
- **Update Student:** Modify a student's name and marks.
- **Delete Student:** Remove a student record.
- **File Handling:** Store records in `students.dat` so they persist between program runs.

## Concepts Used

- C programming
- Structures (`struct`)
- Functions
- File handling (`fopen`, `fread`, `fwrite`)
- Switch-case statements
- Loops and conditional statements
- Binary file operations

## How to Compile and Run

Compile using GCC:

```bash
gcc student_management.c -o student_management
```

Run on Windows:

```powershell
.\student_management.exe
```

## Usage

Run the program and select an option from the menu to add, display, search, update, or delete student records.

**Note:** Student names are currently accepted as single words, and marks must be between 0 and 100.
